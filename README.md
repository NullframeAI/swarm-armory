## Technical focus

The tool collection for the swarm framework: ready-made capabilities (search, files, APIs, data) that agents can be armed with, in a common interface the framework understands.

## Lab notes

- testbed for tool-use research: which tools agents reach for and why
- feeds `relaycore` work on agent-driven pipelines
